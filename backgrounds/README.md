# Green backgrounds

Full-resolution wallpapers for **cogitator-green** belong here. Green is the
repository's native theme, so its backgrounds live at the root; other palettes
use `themes/cogitator-<palette>/backgrounds/`.

Keep `*-preview.png` files in `docs/wallpaper-previews/green/`, not here.
See [the wallpaper guide](../docs/wallpapers.md) for rendering and installation.
