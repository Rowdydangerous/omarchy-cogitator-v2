# Cogitator identity icons

`cog-skull.svg` is the original design reference and is not loaded by the widget.
`../CogSkull.qml` draws the same emblem with native rectangles and a filled
vector path, including transparent facial cuts. Its color is bound directly to
the active theme/status. No SVG image loader, offscreen layer or MultiEffect is
used. Mode/progress/failure indicators remain unchanged.

Use the same monochrome industrial language for future identity icons; retain
clear functional symbols for controls such as mute, sliders and connectivity.
